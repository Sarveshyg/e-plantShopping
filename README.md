# e-plantShopping

## Paradise Nursery Shopping Application

Paradise Nursery is an online plant shopping application built using React and Redux Toolkit. The application allows users to browse different categories of houseplants, add plants to a shopping cart, manage quantities, and view the total cost of their purchases.

## Features

- Landing page for Paradise Nursery
- Navigation between Home, Plants, and Cart
- Multiple plant categories
- Plant cards with:
  - Plant image
  - Plant name
  - Description
  - Price
- Add to Cart functionality
- Add to Cart button becomes disabled after adding a plant
- Dynamic cart item count
- Increase and decrease plant quantities
- Remove plants from the cart
- Individual item subtotal calculation
- Total cart amount calculation
- Continue Shopping button
- Checkout button with a Coming Soon message

## Technologies Used

- React
- React Hooks
- Redux Toolkit
- React Redux
- JavaScript
- CSS
- Vite
